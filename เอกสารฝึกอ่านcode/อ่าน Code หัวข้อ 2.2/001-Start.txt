วิธีหัดอ่านให้ได้ผล:
อ่านก่อนว่าไฟล์นี้ “ทำหน้าที่อะไร”
ดู import ก่อน ว่าใช้เครื่องมืออะไรบ้าง
หา useState และ useEffect เพื่อดูว่ามีข้อมูลอะไรเปลี่ยนได้บ้าง
หา function เช่น handleSubmit, handleChange, handleLoadMore ว่าทำงานตอนไหน
ค่อยดู return (...) ตอนท้าย ว่า UI แสดงอะไรออกมา
เวลางง ให้ถามตัวเองแค่ 3 เรื่อง:
ข้อมูลมาจากไหน
เปลี่ยนตอนไหน
แสดงผลตรงไหน
